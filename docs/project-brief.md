# Scientific Parallax · 科学视差

> 项目定位稿 · 2026-08-31
>
> 本文整理长期关注点，不启动新实验，不替代历史协议或改变已有停止结论。

## 一句话

让 AI 不只在既有科学地图中寻找答案，也参与重新审视地图的画法。

Scientific Parallax 是一个探索 AI 如何参与科学概念形成与问题生成的研究倡议。我们关注的不是某一个预先选定的科学难题，而是科学探索更早的一层：对象、变量、尺度、测量与问题边界如何形成，又能否被修正。

“视差”在这里是一种方法隐喻：用不同表征观察同一份经验，让原本被单一视角遮蔽的假设显现。视角差异不是证据，是否有价值仍由可检验的预测决定。

## 为什么值得关注

在预先给定变量、任务和指标的工作流中，提高预测能力不必然改变我们理解现象的方式。我们想追问：当这些前提本身需要变化时，AI 能参与什么？这不是对全部 AI for Science 工作的概括，也不是已经成立的方法优势。

## 四个长期关注点

### 1. 表征：什么被当作世界的基本单位？

对象、关系、状态变量、尺度与规律的表达方式能否成为可修改的研究对象？新表示需要产生可检验的差别；坐标变换、重命名或复杂度增加本身不算发现。

### 2. 问题：什么样的实验值得被提出？

问题不只是自然语言猜想，而应说明改变什么、测量什么、竞争解释分别预测什么，以及什么结果会改变判断。我们关心新解释能否拓展可检验的问题集合。

### 3. 测量：我们观察到的究竟是什么？

观测是系统经过仪器、采样和处理后的结果。异常可能来自被测系统，也可能来自观测方式。测量模型应是解释的一部分；不能区分时，明确保留不确定性。

### 4. 证据：什么会让一个想法退出？

让预测先于实验，让证据独立于候选的自我评分。记录适用范围、修改成本、负结果与失败谱系。新颖性、模型分歧和漂亮叙事不替代独立检验。

## 一条工作假说，而非锁定的算法

维护多个竞争解释 → 提出区分它们的问题 → 封存预测 → 观测或干预 → 用独立证据更新解释 → 产生新的问题。

范式与问题共进化是这条思路的一种实现候选，不是项目必须捍卫的结论。具体算法、应用领域和实验平台都可以更换，独立证据与可证伪性不能省略。

## 项目分层

- **长期倡议**：以上四个关注点及其方法论联系；这是当前对外表达的中心。
- **方法探索**：可执行表示、问题生成、测量建模与证据约束；是开放的设计空间。
- **具体研究**：未来再选择可验证的问题，并独立审查新颖性与可行性；目前不绑定新课题。
- **历史实验**：保留已有代码、协议和审计，它们检验了有限实现，不代表长期愿景已经被验证。

## 已有工作与诚实边界

- v1 的 Step 7 按预注册规则停止；不解锁旧的后续确认步骤。
- v2 展示了受限合成世界中的潜变量结构恢复能力，不是自然界新规律发现。
- v3 收紧了机制归因，撤回旧消融单独证明中性结构保护的解释；独特算法优势尚未得到支持。
- 测量感知机制归因材料保留为候选研究笔记，不作为这次项目定位的唯一方向，也不在本轮启动实验。

- 后续 LLM 试验又区分出三个不同问题：能否提出隐藏机制、能否从失败历史提出非通用方向、方向是否由具体异常触发。它们分别记录，不能合并成“LLM 已经产生新科学思想”的单一正面结果。
