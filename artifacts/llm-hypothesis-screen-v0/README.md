# LLM hypothesis screen v0

Date: 2026-09-01. Status: development smoke test, not confirmatory evidence.

## Question

Can a language model propose an executable memory mechanism from anonymous two-field
observations and residual summaries without seeing the synthetic generator, its hidden field,
its parameters, repository files, or held-out conditions?

The prompt contains three training conditions, the public two-field reaction-diffusion model,
its fitted predictions, and four summary residuals per field and time. The response must include
three competing complete dynamical models, including at least one model with no additional state.

## Isolation and provenance

- `request.json` and `prompt.txt` contain no occurrence of `latent`, generator cluster names,
  source paths, or held-out condition identifiers; this is also checked in a unit test.
- The retained response was generated by a fresh ephemeral Codex CLI process using
  `gpt-5.6-sol`, reasoning effort `none`, an empty working directory, and a read-only sandbox.
  The prompt instructed it not to use files, tools, or retrieval.
- Generated Python is never run. Equations are parsed into a small arithmetic AST supporting
  state names, declared parameters, `feed`, `kill`, `reaction_scale`, and `lap(state)` only.
- The request and response hashes are recorded in `evaluation.json`.

This was not a frozen one-shot study. Two schema calls were rejected by the API before model
sampling. A subsequent response exposed interface defects: `reaction_scale` was not declared as
a fixed name, and one initial parameter lay outside its stated bounds. The prompt and validator
were corrected before the retained response was requested. This history makes the result an
engineering/development screen, not confirmation. The same local account built and ran the test,
and the model may know the public Gray--Scott family from pretraining.

## Retained proposals and result

The model proposed:

1. a two-field cubic autocatalytic term;
2. a two-field saturating removal term for `v`;
3. a new field `w` obeying `dw = p0*v - p1*w`, which feeds back through an additional `u*v*w`
   reaction term.

The third proposal is qualitatively similar to the withheld mechanism: a slowly decaying field
driven by `v` feeds back into later conversion. It is not the same equation: the proposed `w`
does not diffuse, its coupling differs, and its fitted parameters do not recover the generator.

| Model | Added states | Held-out positive RMSE | Relative change vs baseline |
|---|---:|---:|---:|
| fitted two-field baseline | 0 | 0.058194 | reference |
| cubic autocatalysis | 0 | 0.057526 | 1.15% lower |
| saturating removal | 0 | 0.051640 | 11.26% lower |
| proposed memory field `w` | 1 | 0.056926 | 2.18% lower |

After refitting on the no-extra-process transfer world, all three proposal families turn their
additional effect off at a declared zero boundary and match the two-field held-out RMSE
(`0.002891`). This is only a transfer check. Because the proposal itself was elicited from the
positive case, it is not a false-discovery experiment.

## Interpretation

The screen answers a narrow engineering question: an isolated LLM can propose a qualitatively
appropriate memory-state hypothesis without being given the old three-step Z mutation path.

It does **not** show that the LLM identified the true mechanism. In this small screen, the memory
proposal was not the best predictor; a state-free saturating-removal explanation performed
better. The evidence therefore supports keeping multiple competing explanations and designing a
new discriminating intervention, not declaring that the LLM discovered Z.

Before any scientific comparison, freeze the prompt and parser, generate separate positive and
null prompt cases, repeat across parameter families and model seeds, and compare against random
AST generation, generic evolutionary search, and the historical hand-written Z grammar.
