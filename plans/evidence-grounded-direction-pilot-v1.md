# 证据触发的研究方向：v1 反事实试验计划

> 日期：2026-09-02
>
> 状态：已完成；反事实敏感性通过，但重复稳定性失败，按规则停止
>
> 范围：本地开发试验；研究对象是 LLM 科学方向选择的证据依赖性

## 1. 具体研究问题

当 LLM 从失败实验中主动提出一个研究方向时，方向是否由最强的数值异常触发，还是即使删掉该异常也会从通用科学先验中提出同一个方案？

v0 已证明“可证伪、可执行、写得严谨”还不够：通用因子设计和对称性诊断同样满足这些形式要求。v1 不把恢复隐藏答案作为成功标准，而测试方向选择对观测证据的反事实敏感性。

## 2. 固定证据与反事实

完整证据来自已经冻结的双脉冲实验及其最佳既有无状态解释。第二次脉冲后，`field_b` 的均值、标准差、高值比例和梯度能量均显著高于该解释；最大标准化残差为 8.58。

反事实包保持实验设计、参考预测及第二次脉冲前的全部观测不变，只把第二次脉冲之后的观测替换为参考预测。两个包使用中性哈希编号；模型看不到“完整”或“消融”标签，也看不到生成器、真实机制或仓库。

## 3. 输出自由与执行边界

模型可自由命名研究问题与解释，但必须：

- 引用至少两个精确 `cell_id`；
- 给出两个解释及互斥定性预测；
- 从 5 个已实现的干预族中选择一个两水平实验；
- 预先指定响应字段、特征和时间；
- 写出否定结果如何停止或改变方向；
- 给出文献检索词和最大先验风险。

干预族只限定本地可执行接口，不提供机制候选：等总量改变脉冲半径、第二脉冲幅度、脉冲间隔、控制量 feed、控制量 kill。

## 4. 重复与冻结判据

使用同一模型、同一推理强度和全新隔离上下文：

- 完整证据独立调用 2 次；
- 消融证据独立调用 2 次。

不因内容不理想而改提示或重采样。完整证据的两次输出必须同时满足：

1. 各自引用至少两个绝对标准化残差达到 `max(2, 80% 分位数)` 的单元；
2. 至少引用一个被反事实替换的单元；
3. 两次输出的操作签名完全相同：干预族、响应字段、响应特征、响应时间。

每个消融输出与完整证据的稳定签名至少有两个组成部分不同，才算发生系统性的反事实改变。以上判据全部由代码计算，不使用 LLM 文本相似度或 LLM 裁判。

## 5. 后续实验

只有证据依赖性通过，才对完整证据的第一个冻结提案执行两水平实验。两水平之外的条件固定；不拟合新参数；使用无测量噪声的既有开发世界。相等容差固定为相应特征尺度的 0.5 倍。

观测关系只可能是 `A>B`、`A<B` 或近似相等。若恰好匹配一个解释的冻结预测，则排除另一个解释并更新研究决策；否则记为不确定并停止。

## 6. 新颖性位置与边界

相关研究已经评估最少上下文创意、逐步信息披露、知识图谱证据条件和人工专家偏好。v1 的差异是：对同一个真实模拟失败做单一异常消融，用可执行实验签名而非语言相似度判断方向是否随证据改变，并实际运行幸存方向的实验。

这仍只是一个样例、一个模型和四次调用。通过最多说明该样例中的方向具有反事实证据依赖且能产生决策性实验；不证明一般创造力、发表级原创性或对真实实验室科学的迁移。

## 7. 实际结果与反思

四个 v1.1 输出都通过结构和本地交叉校验。完整证据的两次输出都引用了晚期强异常，也都选择 `field_b` 的 t60 均值，但一个改变第二脉冲幅度，另一个改变脉冲间隔，因此完全操作签名不稳定。消融证据的两次输出都转向 t36 的空间结构并选择等总量脉冲半径，只在读取 t48 还是 t60 上不同。

完整到消融的签名距离为 2 和 3，达到反事实改变标准；完整证据锚定也通过。但完整重复稳定性失败，所以总判定为失败，并按规则没有运行任何下游实验。

这给出两个可复用结论：

1. LLM 不是完全无视证据；删掉晚期异常会把方向从时间/脉冲历史转到空间几何。
2. 证据敏感不等于可靠；同一证据仍可导出不同的首选实验，而且只给数值、不提供已经否决的研究历史，会让模型重新提出 memory/history 路线。

下一版不能事后放宽本轮规则。若继续，应使用新案例，同时把具体数值异常和负结果历史放进同一输入，测试模型能否稳定提出一个没有复活已停止路线的方向。
